API SUMMARY
================================================================================

RDFGraph Class:
  - add_triple(subject, predicate, object)
  - get_entities() → Set[str]
  - get_predicates() → Set[str]
  - get_neighbors(entity) → Set[str]
  - get_path_length(source, target) → int
  - get_common_neighbors(entity1, entity2) → Set[str]
  - get_graph_statistics() → Dict

RelationalGraphNeuralNetwork Class:
  - train_on_triples(num_epochs, learning_rate)
  - predict_link(head, relation, tail) → float
  - rank_candidates(head, relation, candidates) → List[Tuple]
  - get_entity_embedding(entity) → np.ndarray
  - get_similar_entities(entity, top_k) → List[Tuple]

RuleMiningEngine Class:
  - mine_rules() → List[Rule]
  - get_top_rules(k) → List[Rule]
  - get_rules_by_predicate(predicate) → List[Rule]

SemanticInterestingnessMeasure Class:
  - support(body_count, total_count) → float
  - confidence(body_head_count, body_count) → float
  - lift(confidence, head_support) → float
  - coherence(rule, path_metrics) → float
  - combined_interestingness(rule, metrics) → float

NeuralLPHybrid Class:
  - train(num_epochs, learning_rate, mine_rules)
  - predict_link(subject, relation, target) → Prediction
  - rank_candidates(subject, relation, candidates, top_k) → List[Prediction]
  - explain_prediction(prediction) → str
  - get_statistics() → Dict

CrossDomainEvaluator Class:
  - evaluate_all_domains(test_data, negative_samples) → Dict
  - evaluate_single_domain(domain, model, test_triples) → EvaluationResult

================================================================================
CONFIGURATION OPTIONS
================================================================================

NeuralLPHybrid Parameters:
  embedding_dim:    int (default: 64)
                    Range: 32-256
                    Impact: Higher = more expressive, slower

  alpha:            float (default: 0.5)
                    Range: 0.0-1.0
                    Impact: Balance between neural (1.0) and rules (0.0)

  rule_weight:      float (default: 0.4)
                    Range: 0.0-1.0
                    Impact: Weight for rule-based components

Training Parameters:
  num_epochs:       int (default: 10-20)
                    Impact: More = better convergence, risk overfitting

  learning_rate:    float (default: 0.01)
                    Range: 0.001-0.1
                    Impact: Training speed and stability

Evaluation Parameters:
  k_values:         List[int] (default: [1, 3, 5, 10])
                    For Hits@K metrics
